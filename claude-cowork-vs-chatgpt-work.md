# Claude Cowork vs ChatGPT Work (and the Open-Source Third Way)

> Canonical: <https://opensourceclaudecowork.com/claude-cowork-vs-chatgpt-work.html>

Claude Cowork (Anthropic) and ChatGPT Work (OpenAI) compete on nearly identical terms — closed, single-vendor, cloud-only.

| Dimension | Claude Cowork | ChatGPT Work | Kortix (Suna) |
|---|---|---|---|
| Source | Closed | Closed | Source-available (Elastic 2.0) |
| Models | Anthropic only (Opus 4.5) | OpenAI only | Any provider, your own keys |
| Where it runs | Anthropic cloud | OpenAI cloud | Your VPC or on-prem |
| Self-host | No | No | Yes |
| You own the config | No | No | Files in your git repo |

## The real question

Both closed platforms keep your configuration in their product and your data in their cloud. Kortix (Suna) puts agents, skills, memory, and connectors in a git repo you own, running on hardware you control. If sovereignty matters, the choice isn't Claude vs ChatGPT — it's closed vs open.

*Competitor rows reflect publicly documented behavior. Source: [Kortix/Suna](https://github.com/kortix-ai/suna)*
