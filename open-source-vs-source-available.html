Open source vs source-available.

Kortix is open source under Elastic License 2.0: you can self-host it, read the code and modify it. That is enough for the teams this site is written for. This page explains the two license families, where they differ, and what the difference changes for you.

The distinction

Two license families

open source

MIT · Apache-2.0 · GPL

Broad rights to use, modify, and redistribute — including commercially. Examples: CrewAI (MIT), AutoGen.

source-available

Elastic License 2.0 · BUSL

The code is published and self-hostable. Kortix uses Elastic License 2.0 — self-host, read and modify the code.

Why it matters

What the license changes for you

  1. Self-hosting only? Both families work — you can run the code yourself.
  2. Fork and redistribute? You need an open-source license (MIT/Apache-2.0) with the right to redistribute commercially.
  3. Procurement review? Check the license file, not the marketing page — "open" is not a license.
